# EAES — Examination Automation & Evaluation System

A self-hosted, plain-PHP online examination platform for schools and training
centers. Students log in with school-issued credentials, wait in a lobby, sit a timed multiple-choice
exam (with MathJax support for math/science notation), and get instantly
graded; administrators create exam profiles, go live, and pull CSV
scoreboards and per-question difficulty reports.

This is a commercial-ready rebuild of the original prototype: hardened
against SQL injection and brute-force attacks, with hashed passwords,
CSRF protection, a server-authoritative exam timer, autosave, a licensing
gate, an analytics dashboard, and a guided web installer.

## Requirements

- PHP 8.1+ (developed against 8.2) with `pdo_mysql`, `mbstring`, `json`
- MySQL 5.7+ / MariaDB 10.4+
- Apache with `mod_rewrite` (XAMPP ships all of this by default)

No Composer, no Node build step, no framework — copy the folder into
`htdocs/` and go.

## Quick start (XAMPP)

1. Copy the `eaes_exam_system` folder into `C:\xampp\htdocs\` (or your
   platform's equivalent).
2. Start Apache and MySQL from the XAMPP control panel.
3. Visit `http://localhost/eaes_exam_system/installer/install.php` in your
   browser and follow the 4-step wizard (requirements check → database →
   admin account → done). It creates the database, tables, and your
   first admin login for you.
4. Log in at `.../adminlogin.php`, create an exam profile (upload a
   question JSON file — see `docs/ADMIN_GUIDE.md` for the format), and
   click **Start Exam** when you're ready for students to begin.
5. Students go to `.../slogin.php`, log in with the credentials their
   administrator created (see `docs/ADMIN_GUIDE.md` → Students), and wait
   — the exam starts automatically for everyone the moment you start it.

See `docs/INSTALLATION.md` for a from-scratch walkthrough, or
`database/migrate_legacy.php` if you're upgrading an existing install of
the original prototype.

## Project layout

```
eaes_exam_system/
├── app/                  # Application code (never web-accessible directly)
│   ├── Core/             # Database, Session, Csrf, License, Logger, ...
│   ├── Repositories/      # Data access (PDO, prepared statements only)
│   ├── Services/         # Grading, exam import, report generation
│   ├── bootstrap.php     # Included by every public entry script
│   └── config.php
├── assets/                # CSS, JS, images, bundled MathJax
├── database/
│   ├── schema.sql         # Fresh-install schema
│   └── migrate_legacy.php # Upgrade helper for the old prototype's data
├── docs/                  # This documentation set
├── installer/             # First-run web setup wizard
├── partials/               # Shared admin header, etc.
├── storage/                # Logs + install lock (never web-accessible)
├── *.php                   # Public entry points (slogin, examportal, ...)
└── .env                    # Generated by the installer (never commit/share)
```

## Key improvements over the original prototype

| Area | Before | After |
|---|---|---|
| Security | Raw string-concatenated SQL, plaintext passwords | PDO prepared statements everywhere, bcrypt password hashing (with transparent legacy upgrade), CSRF tokens, login rate limiting, security headers |
| Timer | Client-only `setInterval`, resets on refresh | Server-authoritative `started_at`, immune to refresh/tampering, resynced from the server on every autosave |
| Autosave | `localStorage` only — lost on a new device/browser | Answers/flags persisted server-side every 15s (configurable) and on exit |
| Grading | Trusted the client's submitted answers | Grades from the server's own autosaved answer copy |
| Architecture | One monolithic file per page mixing SQL, HTML, JS | Repository/Service layers, shared config, shared UI partials/CSS |
| Reporting | CSV scoreboard only | CSV scoreboard + per-question accuracy/difficulty report + analytics dashboard |
| Licensing | None | Offline, signed and hardware-bound `.lic` activation gate (`app/Core/License.php`) |
| Installation | Manual SQL import + hand-edited `db.php` | Guided 4-step web installer |
| History | A student's new exam attempt overwrote their previous score | Every (student, exam) attempt is its own row — full history retained |
